The pull list (**Calendar → Pull List**) is the weekly view of your library: what's coming out and what already shipped, grouped into new-comic-book-day (Wednesday-anchored) weeks from one week back to four weeks ahead.

Each issue shows its status:

- **have** — file on disk
- **grabbed** — sent to the download client
- **missing** — released, monitored, no file
- **unreleased** — not out yet
- **unmonitored** — hidden by default; use the toolbar toggle to show

Per-issue search is available on missing issues, and each week section has a **Search N missing** action that queues searches for everything missing that week.

The page opens on the current week; last week collapses behind a link.
